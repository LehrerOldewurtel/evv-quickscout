# QuickScout VIP 7.9.9 RC – Gegnerfeld Touch/Pencil

- Gegnerfeld: Pointer Capture auf dem Spielfeld statt auf den Spielerbuttons. Damit bleiben Ziehbewegungen auch außerhalb des Spielerbuttons aktiv.
- Direktes Verschieben mit Finger, Pencil oder Maus; Touch-Scrollen/Zoom auf dem Feld deaktiviert, außerhalb bleibt die Seite scrollbar.
- Separater Markierungsmodus: Antippen einer beliebigen Feldstelle setzt einen deutlich sichtbaren roten Punkt, auch auf bisher von Spielern verdeckten Flächen.
- Mehrere Skizzenmarkierungen werden lokal im Spielstand gespeichert. Letzte Markierung einzeln löschen oder gesamte Skizze zurücksetzen.
- Markierungen sind **Skizzenpunkte**, keine statistisch erfassten Kills. Bereits erfasste Rallyes bleiben unverändert.
- Cache/Versionsnummer auf 7.9.9-rc aktualisiert.
