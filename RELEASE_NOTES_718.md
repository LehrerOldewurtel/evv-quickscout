# 7.18.0 K1: vier Annahmespieler

K1 zeigt Libero plus drei weitere Annahmespieler (darunter optional den vorderen Mittelblocker). Bei fehlendem Libero werden vier reguläre Spieler angeboten. Annahmeplanung pro Rotation akzeptiert vier Spieler. Die tatsächliche Libero-Wechsellogik wurde nicht verändert.
