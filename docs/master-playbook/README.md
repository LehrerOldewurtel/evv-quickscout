# EVV QuickScout Codex Paket

- `CODEX_AUFTRAG.md`: vollständiger Fertigstellungsauftrag.
- `formationen_5_1.json`: sechs kanonische 5:1-Regelrotationsvorlagen, neutrale überlappungssichere Startpositionen, Libero-Kandidaten und K2-Trainerprinzipien.

**Grenze:** Die früher im Chat gezeigten externen Diagramme sind in diesem Paket nicht pixelgetreu digitalisiert. Die Datei liefert fachlich klare Rotations- und Datenvorlagen, keine behauptete exakte Kopie der Referenzbilder. Codex muss konkrete K1-Annahme- und Laufwegvorlagen daraus ausarbeiten und validieren.

## Nutzung
ZIP im Codex-Chat hochladen und den Text aus `CODEX_AUFTRAG.md` als Arbeitsauftrag verwenden. Alternativ Dateien einzeln hochladen. Codex soll selbst die Dateien im Repository einchecken und eine PR erstellen.
