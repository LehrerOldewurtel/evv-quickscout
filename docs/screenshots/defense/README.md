# Vier EVV-Systeme · visuelle Browserbelege

Synthetischer Kader/Nummern, keine echten Spieldaten. Die Bilder zeigen EVV-R2,
damit Regelposition und rollenbasierte taktische Zone sichtbar unterschieden sind.
Koordinaten sind Vorschläge aus den schriftlichen Vorgaben; die sechs erwähnten
Lehrabbildungen lagen hier nicht als lesbare Dateien vor.
