# Praxistest-Korrekturen · visuelle Browserbelege

Synthetische Spiele, frische Chromium-Kontexte und echte UI-Eingaben.
Reproduzierbar mit `node scripts/capture-practice.cjs` gegen Loopback-Port 4186.
Keine echten Matchdaten, keine injizierten Formationen. Nummern außerhalb des
bekannten EVV-Kaders sind ausdrücklich synthetische Testnummern.
